Join a table

Tap Join a table and choose the same way the host chose. Type the host's code, or tap Scan a code and scan the square on the host's screen, then tap Join.

Over Bluetooth the host's phone has to be visible: Android asks the host when the table opens, and the host's menu can make it visible again. A phone you have joined can be saved, and saved phones are called first the next time.
