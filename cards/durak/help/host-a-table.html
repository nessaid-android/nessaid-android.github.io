Host a table

One phone hosts the table: it deals, and the others join it. Tap Host a table, choose how the phones will reach each other, and open the table.

Read the code on the screen out to the others, or let them scan it. Seat bots in any empty chairs with Add bots, and move players and bots between chairs with the arrows. Table settings say how the game is played.

Tap Start the game. Everybody with a phone at the table is asked to agree, and then the cards go out.
